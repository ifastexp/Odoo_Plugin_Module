# iFAST Express for Odoo 17.0

The `ifast_express` module: iFAST Express shipping method (UAE), checkout prices, send deliveries, AWB labels and tracking.

Install from the Odoo App Store, or copy `ifast_express` into your addons path. Then Inventory > Configuration > Settings > iFAST Express > Connect.
